Privacy Policy

This privacy policy explains how the Library Robot Application handles data and uses Google Drive services.

About the App

This application is used in libraries to support visitors through basic conversations and photo-taking using a robot. Each library is assigned a dedicated Google account managed by the library itself.

When a library visitor agrees to take a photo, the robot captures the image and uploads it to the library's Google Drive using the drive.file scope. A QR code is then generated containing a download link to the image file.

The visitor can scan the QR code using their smartphone or personal device to download their photo. After the download is complete, the uploaded photo is promptly deleted from Google Drive.

Data Access and Usage

  • The app accesses only the files it uploads itself.
  • It does not access other contents of the Google Drive.
  • No personal data is stored on external servers.
  • No data is shared with third parties.

Google Permissions

The app uses the following Google OAuth scope:

  • https://www.googleapis.com/auth/drive.file: Used to upload and delete the visitor’s photo.

Intended Use

This app is intended for use in physical library environments only. It is not distributed publicly and is not intended for personal or commercial use outside the library system.
